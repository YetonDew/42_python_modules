# 🎮 Python Module 03

> Data structures & generators exercises covering sys.argv, tuples,
> sets, dictionaries, generators, and comprehensions — all with a
> gaming theme.

## Exercises

| # | Directory | File(s) | Topic |
|---|-----------|---------|-------|
| 0 | `ex0/` | `ft_command_quest.py` | Command-line arguments with sys.argv |
| 1 | `ex1/` | `ft_score_analytics.py` | Score parsing, validation & statistics |
| 2 | `ex2/` | `ft_coordinate_system.py` | Tuples, unpacking & distance calculation |
| 3 | `ex3/` | `ft_achievement_tracker.py` | Sets: union, intersection & difference |
| 4 | `ex4/` | `ft_inventory_system.py` | Dictionaries: CRUD & analysis |
| 5 | `ex5/` | `ft_data_stream.py` | Generators: fibonacci, primes & event streams |
| 6 | `ex6/` | `ft_analytics_dashboard.py` | List, dict & set comprehensions |

## How to run

Each exercise can be run individually:

```bash
python3 ex0/ft_command_quest.py arg1 arg2
python3 ex1/ft_score_analytics.py 100 200 300
python3 ex2/ft_coordinate_system.py
python3 ex3/ft_achievement_tracker.py
python3 ex4/ft_inventory_system.py sword:10 shield:5 potion:3
python3 ex5/ft_data_stream.py
python3 ex6/ft_analytics_dashboard.py
```

Lint all files:

```bash
flake8
```
