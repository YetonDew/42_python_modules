# 🌱 Python Module 02

> Exception handling exercises covering try/except, multiple error types,
> custom exceptions, finally blocks, raising errors, and a full garden
> management system.

## Exercises

| # | Directory | File(s) | Topic |
|---|-----------|---------|-------|
| 0 | `ex0/` | `ft_first_exception.py` | Basic try/except & input validation |
| 1 | `ex1/` | `ft_different_errors.py` | Catching multiple error types |
| 2 | `ex2/` | `ft_custom_errors.py` | Custom exception classes |
| 3 | `ex3/` | `ft_finally_block.py` | Finally block & resource cleanup |
| 4 | `ex4/` | `ft_raise_errors.py` | Raising exceptions with raise |
| 5 | `ex5/` | `ft_garden_management.py` | Full garden management system |

## How to run

Each exercise can be run individually:

```bash
python3 ex0/ft_first_exception.py
python3 ex1/ft_different_errors.py
# ...
python3 ex5/ft_garden_management.py
```

Lint all files:

```bash
flake8
```
