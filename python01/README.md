# 🌱 Python Module 01

> Object-oriented Python exercises covering classes, inheritance,
> encapsulation, factory patterns, and multi-level inheritance.

## Exercises

| # | Directory | File(s) | Topic |
|---|-----------|---------|-------|
| 0 | `ex0/` | `ft_garden_intro.py` | User input & plant info display |
| 1 | `ex1/` | `ft_garden_data.py` | Classes & blueprinter method |
| 2 | `ex2/` | `ft_plant_growth.py` | Growth simulation with inheritance |
| 3 | `ex3/` | `ft_plant_factory.py` | Factory pattern for plant creation |
| 4 | `ex4/` | `ft_garden_security.py` | Encapsulation & data validation |
| 5 | `ex5/` | `ft_plant_types.py` | Inheritance hierarchy |
| 6 | `ex6/` | `ft_garden_analytics.py` | Multi-level inheritance & analytics |

## How to run

Each exercise can be run individually:

```bash
python3 ex0/ft_garden_intro.py
python3 ex1/ft_garden_data.py
# ...
python3 ex6/ft_garden_analytics.py
```

Lint all files:

```bash
flake8
```
