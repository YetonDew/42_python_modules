# 🌱 42 Python Modules

> A collection of Python modules covering fundamentals, object-oriented
> programming, and error handling through garden-themed exercises.

## Modules

| Module | Directory | Description |
|--------|-----------|-------------|
| 00 | `python00/` | Variables, I/O, conditionals, loops, recursion, and functions |
| 01 | `python01/` | Classes, inheritance, encapsulation, and factory patterns |
| 02 | `python02/` | Exception handling and custom errors |

## How to run

Each exercise can be run individually from its module directory:

```bash
python3 python00/ex0/ft_hello_garden.py
python3 python01/ex0/ft_garden_intro.py
python3 python02/ex0/ft_first_exception.py
```
