# 🌱 42 Python Modules

> A collection of small, focused Python exercises used for learning
> fundamentals, object-oriented design, error handling, and simple
> projects. Exercises are organized by numbered modules (python00..python10).

## Modules

| Module | Directory   | Focus                                                  |
| ------ | ----------- | ------------------------------------------------------ |
| 00     | `python00/` | Basics: variables, I/O, conditionals, loops, recursion |
| 01     | `python01/` | OOP: classes, inheritance, factories, encapsulation    |
| 02     | `python02/` | Errors: exceptions, custom errors, finally blocks      |
| 03     | `python03/` | Small projects: CLI tools, analytics, data handling    |
| 04     | `python04/` | File/archive handling and security-related exercises   |
| 05     | `python05/` | Data-processing utilities and pipelines                |
| 06     | `python06/` | Alchemy-themed examples and package layout             |
| 07     | `python07/` | Game/creature simulations and strategies               |
| 08     | `python08/` | Module packaging, requirements and project layout      |
| 09     | `python09/` | Misc exercises (placeholders)                          |
| 10     | `python10/` | Advanced or extra exercises (placeholders)             |

## Quick start

- Recommended Python: `3.10+` (use your environment or `pyenv`/`venv`).
- To run a single exercise file:

```bash
python3 python01/ex0/ft_garden_intro.py
```

- To run many exercises, use a shell loop from repository root (example):

```bash
for f in python*/**/*.py; do python3 "$f" || break; done
```
